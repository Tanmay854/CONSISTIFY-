# Premium content access

- Signed-out users may browse book covers and Long Game thumbnails, but opening either requires account creation or sign-in.
- All full book content is restricted to premium accounts by backend row-level access rules.
- Signed-in free accounts may play only the single Long Game or legacy Calm State video marked by an administrator as the free preview.
- Premium accounts, administrators, uploaders, and content owners retain their appropriate access.
- Only one Long Game/Calm State video can be marked as the free preview at a time.
